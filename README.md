# Merge Sorted Arrays — TypeScript

## Setup & Installation

Requires [Node.js](https://nodejs.org/) v18 or higher.

```bash
git clone https://github.com/napat-atng/merge-project.git
cd merge-project
npm install
```

## Running Unit Tests

```bash
npm test
```

## Dependencies & Scripts

| Package       | Purpose                        |
| ------------- | ------------------------------ |
| `typescript`  | TypeScript compiler            |
| `jest`        | Test runner                    |
| `ts-jest`     | Run TypeScript tests with Jest |
| `@types/jest` | Type definitions for Jest      |
| `@types/node` | Type definitions for Node.js   |

| Script   | Command                 |
| -------- | ----------------------- |
| Test     | `npm test`              |
| Coverage | `npm run test:coverage` |
